# `supersol-token`

SuperSol (SSOL) Token program for SuperSol Layer 2 blockchain.

## Overview

`supersol-token` is a reimplementation of the SPL Token program, one of the most popular programs on Solana. The purpose is to have an Layer 2 token `SuperSol (SSOL)` on SuperSol blockchain, while being fully compatible with the original implementation &mdash; i.e., support the exact same instruction and account layouts as SPL Token, byte for byte.

## Features

- `no_std` crate
- Same instruction and account layout as SPL Token
- Minimal CU usage
